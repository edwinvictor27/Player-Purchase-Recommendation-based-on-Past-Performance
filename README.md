
# 🏏 Player Purchase Recommendation Based on Past Performance

## 📌 Project Overview

This project is a data-driven cricket player recommendation system developed out of personal interest in **Data Science, Machine Learning, and Sports Analytics**.

The application analyzes historical player performance and uses domain-specific performance metrics to support player purchase recommendations.

Machine learning models, including **Random Forest Classifier and XGBoost**, were explored as part of the analytical approach. The project also incorporates similarity-based player recommendations to compare performance profiles.

The objective is to demonstrate how machine learning and domain knowledge can support data-driven decision-making in sports recruitment.

---

## 🎯 Objectives

- Analyze historical cricket player performance.
- Develop performance metrics based on cricket domain knowledge.
- Apply machine learning classification techniques.
- Compare player performance profiles.
- Generate player purchase recommendations.
- Build a Python-based application for accessing the recommendation system.

## 🔍 Methodology

### 1. Data Preparation

Historical cricket player performance data was prepared for analysis and model development.

### 2. Domain-Specific Feature Engineering

Performance metrics were designed using cricket domain knowledge to support meaningful player evaluation and comparison.

These metrics form the basis of the recommendation approach.

### 3. Machine Learning

The project uses machine learning techniques, including:

- Random Forest Classifier
- XGBoost

The models were explored for player performance classification based on the selected features.

### 4. Similarity-Based Recommendation

The system uses performance-related features to compare players and support purchase recommendations.

The recommendation logic is based on defined performance metrics and cricket domain knowledge.
